## 4. 3級・4級と数学の前提

JSAは2級の試験範囲に3級・4級の範囲が含まれると明記している。3級・4級に掲載されている項目を、それだけの理由でSfQC上の必須前提にしていない。対応するレッスンが後続の目標に必要かを前提マップで別に判定した。

4級表p.1の「データの基礎（母集団、サンプリング、サンプル）」「データの種類（計量値、計数値）」「平均とばらつきの概念」「平均と範囲」は、data-types、population-sample、descriptive-statisticsへ重複単元を作らず対応する。3級表p.1のデータの取り方、基本統計量とグラフ、相関係数、QC七つ道具、正規・二項分布、管理図、工程能力指数は、それぞれ該当するsourceItemId / lessonIdで扱う。

分数・比・割合、指数・平方根、式変形、総和記号、数え上げ、確率の初歩はJSAレベル表に独立項目として記載されない数学の橋渡しである。公式項目のsourceItemIdは付けず、SfQC独自の前提lessonとして別文書に定義する。

## 5. 2級項目の相互照合・未対応の扱い

- M（手法編）の2級欄に◎または○がある統計・品質管理手法項目は、SRC-0001〜SRC-0059に1行ずつ登録した。項目の意味が異なるため、相関する複数の公式要求は別IDとした。重複する同一要求は級ごとの別項目にせず、同じIDの出典欄にまとめた。
- Mに2級欄の記載がない「有限母集団からのサンプリング（超幾何分布など）」「一様分布」「指数分布」「二次元分布」「共分散」「3つ以上の母分散に関する検定」「適合度の検定」「工程能力指数の区間推定」「計数選別型・調整型抜取検査」「多元配置・乱塊法等の1級のみの実験手法」「多変量解析法・重回帰分析等」は、2級範囲の行としては採番しない。2級表に別個の要求がある場合はその表の記述を優先して記載し、1級のみのマークを2級要求と推定しない。
- Mの新QC七つ道具では2級列が7項目すべてに印を付ける一方、L2 p.1に個別項目として列挙されるのは親和図法・連関図法・系統図法・マトリックス図法の4項目である。残るアローダイアグラム法・PDPC法・マトリックスデータ解析法はMとL3の根拠を併記し、L2に明記がないことを隠さない。
- L2 p.1の管理図欄はPDFテキスト抽出で「X − s管理図」と読める一方、Mは「Xbar-s管理図」と記載する。字形は未確認のため、SRC-0040の対応名はMに合わせ、表記差を残した。
- SRC-0056〜SRC-0059は2級マークのある信頼性工学項目だが、採用する範囲・深さを保留した。SRC-0064も実践編との境界にあるため保留。未対応を隠さず、次の教育内容レビューで決める。
- 公式資料にない教材コンテンツの転載は行わず、項目名・級別マーク・出典位置だけを記録する。
