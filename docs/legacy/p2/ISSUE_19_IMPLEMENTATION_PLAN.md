完了時には、次をすべて確認する。

- 生成画像や外部素材を使わない。汎用グラフ基盤や全教材・全画面の実装へ広げない。

## 実装範囲と設計判断

このIssueでは、固定3値を描く専用SVGコンポーネント、教材レジストリのFIG定義とfigureRef、数値テスト、および図を表示して確認できる最小の接続を実装する。Lesson UI全体や他教材の描画は含めない。

計算は元データを使い、丸めはラベル表示だけで行う。横軸はカテゴリ尺度の「観測番号」、縦軸は線形尺度の「測定値（mm）」とする。y軸は1.0–3.0 mm、0.5 mm刻みの目盛にし、各値を点で示す。平均の水平線と各値から平均までの符号付き偏差を線分・数値ラベルで重ね、線種や記号でも区別する。長い説明や細かな計算はSVG内に置かない。figcaptionでは観測番号・観測値・偏差・偏差の二乗を行ごとに対応付け、`(−16/15 mm)² = 256/225 mm²`、`(+2/15 mm)² = 4/225 mm²`、`(+14/15 mm)² = 196/225 mm²`、合計`456/225 = 152/75 mm²`を示す。単位が偏差ではmm、二乗値と平方和ではmm²になることを明示する。観測2は`+2/15 mm ≈ +0.133 mm`と書く。二乗値を別のグラフ系列にはしないが、二乗値を一切表示しないという意味にはしない。

図はインラインSVGとして出力する。`FigureDefinition.altText`には図の構造と要点だけを簡潔に記し、その値をSVG内の`<desc>`として一度だけ出力する。`<title>`は図の短い名前にする。SVGには`role="img" aria-labelledby="{title-id} {desc-id}"`を付け、`aria-labelledby`は同じSVG内のtitleとdescだけを参照する。HTMLの`<figure>`内には通常の`<figcaption>`を置き、各観測・偏差・二乗値の対応、合計、単位、分散の分母を記す。SVGからfigcaptionへの`aria-describedby`等は付けず、同じ長文を画像の説明とキャプションの双方に関連付けない。figcaptionは図に続く本文として読み上げで到達できることを確認する。現在の本文領域は幅320 CSS pxで約230pxになるため、SVGの縮小だけで読めるとはみなさない。viewBox 360に対して約64%の表示になり、12 viewBox単位の文字は約7.7 CSS px、観測2の偏差線8.8単位は約5.6 CSS pxになる見込みである。従って、短い線や縮小後のSVG文字だけで値を判別できるとは主張せず、対応するHTMLの値一覧から確実に意味を読めるようにする。数値ラベルと詳細凡例は折り返せるHTMLに置き、HTML文字をSVGと一緒に縮小しない。静的な図に操作機能やタブ移動先は追加しないため、キーボード確認では図が不要なフォーカス停止を作らず、既存の画面操作を妨げないことを確認する。

図を描くのは専用コンポーネント1点だけとし、グラフライブラリ、任意データ向けの汎用グラフエンジン、生成アセット、外部通信、学習履歴・保存形式の変更は加えない。図を教材本文へ実際に接続するため、現在の `#/lesson` には分散節の当該figureRefを表示する細い経路だけを設ける。将来のIssue #24ではこの表示箇所を実データの本文block rendererに置き換え、同じ専用図コンポーネントを利用する。

図の追加は教材内容の改訂として扱い、`descriptive-statistics` のrevisionを2から3へ上げる。section ID、前提関係、sourceItemIds、curriculumRevisionは変えない。

- 数値計算だけでは座標の上下反転や線の終点間違いを検出できないため、data moduleの独立期待値テストに加え、production previewのReact描画済みSVG DOMから点・平均線・偏差線の座標属性と観測順を読み取り、同じ独立期待値と照合する。
- 320 CSS px幅で本文が約230pxになる制約を踏まえ、長文・凡例・数値一覧は折り返せるHTMLに置き、短い観測2の偏差線だけで値が分かるとは主張しない。観測2の`+2/15 mm ≈ +0.133 mm`を含むHTML対応行で意味を得られることを受入条件にする。幅320 CSS px・表示倍率100%と実ブラウザー200%を別々に記録し、ブラウザー名、ズーム前後viewport、スクリーンショットを残す。
- `FigureDefinition.altText`は図の構造・要点を伝える短文にし、SVGの`<title>`と`<desc>`を`aria-labelledby`で参照する。詳細計算と分母N・n・n−1は通常のHTML figcaptionに置き、SVGから同じfigcaptionをARIA参照しない。読み上げで図の意味と必要数値へ到達でき、長文を二重に読まないことを確認する。二乗値はHTMLに示すがSVGの別系列にはしない。
